# Terminal Snake

A small Snake game that runs in your terminal, written in Python.

## Run

```bash
python3 snek.py
```

On Windows, install `windows-curses` first:

```bash
py -m pip install windows-curses
py snek.py
```

## Controls

- **Arrow keys** or **WASD** — move
- **P** — pause or resume
- **Q** — quit
- **R** — retry after game over
